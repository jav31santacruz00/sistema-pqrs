Sistema PQRS

Sistema para la recepción, clasificación y gestión de Peticiones, Quejas, Reclamos y Sugerencias (PQRS).

Permite registrar solicitudes, asignarlas al área correspondiente y realizar seguimiento a su estado, además de controlar los tiempos de respuesta según el tipo de PQRS.
